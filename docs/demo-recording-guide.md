# 🎬 Demo Recording Guide

## Professional Demo Video for Portfolio & Recruitment

---

## 📋 Pre-Recording Checklist

- [ ] Resolution set to **1920×1080** (Full HD)
- [ ] Browser: Chrome (maximized, no bookmarks bar)
- [ ] Dark mode enabled (system + browser)
- [ ] Close all other tabs and notifications
- [ ] Backend running (`python run.py` on port 5000)
- [ ] Frontend running (`npm run dev` on port 3000)
- [ ] Login page loaded and ready
- [ ] OBS Studio / Loom / ScreenPal configured
- [ ] Microphone tested (if narrating)
- [ ] Screen recording area = browser only
- [ ] No personal data visible anywhere
- [ ] Mouse cursor visible with smooth movements
- [ ] Record at 30fps minimum

---

## 🎙️ Narration Script (2:10 total)

### Scene 1: Login (0:00 – 0:12)

**Caption:** *Enterprise QA Automation Platform*

**Narration:**
> "This is the Playwright Automation Dashboard — an enterprise-grade QA platform I built from scratch using React, TypeScript, Flask, and Tailwind CSS. Let me walk you through the key features."

**Action:**
- Show the split-layout login page
- Hover over feature cards on the right
- Click "Admin" quick-access button (credentials auto-fill)
- Click "Sign In"

---

### Scene 2: Dashboard (0:12 – 0:35)

**Caption:** *Real-Time Analytics Dashboard*

**Narration:**
> "The dashboard gives a real-time overview — 150 projects, 5,000 test cases, 20,000 executions with a 91.7% pass rate. Charts update automatically with live polling. You can see execution trends, browser distribution, test coverage, and recent runs all in one view."

**Action:**
- Slow pan down through KPI cards
- Hover over the Pass/Fail trend chart (show tooltip)
- Point at the Coverage radial gauge
- Glance at the Recent Runs feed

---

### Scene 3: Projects (0:35 – 0:48)

**Caption:** *Project Management*

**Narration:**
> "Each project is organized with environment configurations, framework settings, and team assignments. Full CRUD with search, filtering, and real-time updates."

**Action:**
- Show the projects grid (30 cards)
- Type in search field to filter
- Click "New Project" button — show the modal
- Close the modal

---

### Scene 4: Test Suites (0:48 – 0:58)

**Caption:** *Test Suite Organization*

**Narration:**
> "Test suites are categorized by type — Smoke, Regression, Sanity, API, Security. Each suite shows its test count and priority with color-coded badges."

**Action:**
- Scroll through suite cards
- Point out the type badges (different colors)
- Hover one card (show the hover effect)

---

### Scene 5: Test Cases (0:58 – 1:08)

**Caption:** *Test Case Management*

**Narration:**
> "The test case registry supports priority levels, modules, file paths, and ownership. The table supports search, sort, and pagination for thousands of records."

**Action:**
- Show the table with 50 rows
- Use search to filter
- Point at priority badges

---

### Scene 6: Execution Center (1:08 – 1:30)

**Caption:** *Test Execution Engine*

**Narration:**
> "The Execution Center lets you run tests against any browser and environment. Executions run in background threads with real-time status updates. You can view detailed results, failure analysis with stack traces, and a terminal-style execution log."

**Action:**
- Show the executions list with status filters
- Click "Run Tests" — configure browser, environment
- Start execution (show it go to "queued")
- Click into an execution detail page
- Show Results tab → Failures tab → Log tab

---

### Scene 7: Reports (1:30 – 1:38)

**Caption:** *Report Generation & Export*

**Narration:**
> "Reports can be exported as JSON, CSV, or HTML. Every report includes execution summaries, failure details, and metadata."

**Action:**
- Show reports table with format icons
- Hover over download button

---

### Scene 8: Analytics (1:38 – 1:50)

**Caption:** *Deep Analytics & Insights*

**Narration:**
> "The analytics module provides success rate trends, most-failed tests, browser comparisons, execution duration tracking, and pass/fail volume charts — all with 30-day historical data."

**Action:**
- Pan across the 6 KPI cards
- Hover over the Success Rate chart
- Point at the Most Failed Tests bar chart
- Scroll to Pass/Fail Volume area chart

---

### Scene 9: Scheduler + Users (1:50 – 2:00)

**Caption:** *Scheduling & Team Management*

**Narration:**
> "Schedules support cron expressions for automated nightly regressions. The admin panel provides role-based user management with full CRUD."

**Action:**
- Show scheduler with active toggles
- Quick switch to Users page
- Show role badges

---

### Scene 10: Closing (2:00 – 2:10)

**Caption:** *Built with React • TypeScript • Flask • Playwright*

**Narration:**
> "The entire platform features JWT authentication with token revocation, rate limiting, security headers, code splitting, and is deployable via Docker, Vercel, and Render. Thank you for watching."

**Action:**
- Return to Dashboard
- Hold on the full dashboard view for 3 seconds
- Fade out

## 🎥 Camera Movement Suggestions

| Scene | Movement | Effect |
|-------|----------|--------|
| Login | Static, slight zoom in | Focus attention |
| Dashboard | Slow pan down | Reveal data progressively |
| Charts | Mouse hover with pause | Show interactive tooltips |
| Tables | Smooth scroll down | Demonstrate data density |
| Modals | Quick open/close | Show UI responsiveness |
| Execution | Click through tabs | Show feature depth |
| Analytics | Slow horizontal pan | Cover multiple charts |
| Closing | Pull back to full view | Grand finale |

## 📐 Post-Production

- Add gentle background music (Lo-Fi or ambient tech)
- Add caption overlays at each scene transition
- Fade transitions between scenes (0.5s)
- Export as MP4 at 1080p / 30fps
- Thumbnail: Use the Dashboard screenshot with title overlay
- Upload to: YouTube (unlisted), LinkedIn, Portfolio site

## 🎯 Recruiter-Friendly Highlights

Ensure these are visible in the video:

1. **Scale** — Show the numbers: 150 projects, 5000 tests, 20000 executions
2. **Real-Time** — Show live polling and status updates
3. **Architecture** — Mention React + TypeScript + Flask + Docker
4. **Security** — Mention JWT + RBAC + Rate Limiting
5. **Code Quality** — Mention TypeScript strict, 42 smoke tests passing
6. **Deployment** — Mention Docker + Vercel + Render + GitHub Actions
7. **UI/UX** — Show glassmorphism, animations, responsive design
8. **Full-Stack** — Frontend + Backend + Database + DevOps
