# 🎬 Demo Script

Use this script when recording a walkthrough video (2-3 minutes).

---

## Recording Setup

- **Resolution**: 1920×1080
- **Browser**: Chrome (dark mode)
- **Tool**: OBS Studio or Loom
- **Speed**: Normal pace, no rush

---

## Script

### 1. Login (10s)
- Show the split-layout login page
- Click "Admin" quick-access button
- Click "Sign In"
- Transition to Dashboard

### 2. Dashboard (20s)
- Pan across KPI cards (150 projects, 5000 tests, 91.7% pass rate)
- Hover over Pass/Fail trend chart
- Point out the live "Running" indicator
- Show Browser Distribution pie chart
- Scroll to Recent Runs feed

### 3. Projects (15s)
- Show the 30-project grid
- Use search to filter
- Click "New Project" — show modal
- Close modal

### 4. Test Suites (10s)
- Show categorized suites (Smoke, Regression, API, Security)
- Highlight type badges and test case counts

### 5. Test Cases (10s)
- Show the table with 50 cases
- Point out priority badges and module column
- Use search filter

### 6. Executions (20s)
- Show status filter tabs (All, Running, Passed, Failed)
- Click "Run Tests" — show execution config modal
- Start an execution
- Show real-time status update
- Click into execution detail — show results + failure analysis + log

### 7. Analytics (15s)
- Show 6 KPI cards
- Pan across all charts (Success Rate, Most Failed, Browser, Duration)
- Highlight the Pass/Fail volume chart

### 8. Reports (10s)
- Show the reports table with different formats
- Click download icon

### 9. Scheduler (10s)
- Show scheduled jobs with active toggles
- Point out cron expressions and next-run times

### 10. Users (10s)
- Show user management table
- Point out role badges (Admin vs QA Engineer)

### 11. Close (5s)
- Return to Dashboard
- Pause on the full view
- End recording

---

## Total Duration: ~2:15
