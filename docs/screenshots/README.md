# 📸 Screenshots

Capture screenshots of the running application for the README:

## How to Capture

1. Start the application (`npm run dev` + `python run.py`)
2. Login with `admin / 1231231234`
3. Take screenshots of each page at **1440×900** resolution
4. Save as PNG with these filenames:

| File | Page |
|------|------|
| `login.png` | Login page (split layout view) |
| `dashboard.png` | Dashboard with all charts populated |
| `projects.png` | Projects grid view |
| `testsuites.png` | Test Suites with type badges |
| `testcases.png` | Test Cases table |
| `executions.png` | Execution Center with status filters |
| `execution-detail.png` | Single execution with results + log |
| `analytics.png` | Analytics page with all charts |
| `reports.png` | Reports table with export buttons |
| `screenshots-gallery.png` | Screenshots gallery grid |
| `videos-gallery.png` | Video recordings gallery |
| `scheduler.png` | Scheduler with active toggles |
| `users.png` | User management table |
| `settings.png` | Settings form |
| `responsive.png` | Mobile viewport composite |

## Recommended Tools

- **Browser**: Chrome DevTools (Device Toolbar for responsive)
- **Screenshot**: Built-in `Ctrl+Shift+S` (Chrome area capture)
- **GIF Recording**: [LICEcap](https://www.cockos.com/licecap/) or [Kap](https://getkap.co/)
